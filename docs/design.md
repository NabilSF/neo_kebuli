# Neo KBLI Design System

## Design Philosophy

Neo KBLI adopts a modern government-grade minimal interface focused on:
- Information-first experience
- Search-centric interaction
- Minimal cognitive load
- Professional institutional appearance
- Fast interaction and accessibility

# Typography

Font Family:
- Inter

Typography Scale:
- H1 → 56px
- H2 → 40px
- H3 → 28px
- Body → 16px
- Small → 14px

Rules:
- Large whitespace
- Medium font weight
- High readability
- Comfortable line height

---

# Layout Rules

- Maximum content width: 1280px
- Use generous whitespace
- Avoid crowded interfaces
- Use responsive containers
- Use soft border radius
- Avoid heavy shadows

---

# UI Components

## Buttons
- Rounded-xl
- Soft hover transitions
- Large clickable area

## Cards
- Rounded-2xl
- Thin border
- Subtle shadow

## Search Bar
- Primary feature
- Large width
- Center aligned
- Fast interaction

## Tables
- Clean
- Minimal borders
- Zebra optional
- Responsive scroll

---

# UX Rules

- Minimize user confusion
- Keep navigation shallow
- Focus on readability
- Reduce excessive animations
- Use consistent spacing
- Mobile-friendly interactions

---

# Accessibility

- High color contrast
- Keyboard navigable
- Accessible button sizes
- Semantic HTML
- Responsive typography

---

# Performance Standards

- Lighthouse Performance > 90
- FCP under 2 seconds
- Lazy loading for images
- Pagination for large datasets
- Prevent N+1 queries
- Use eager loading
- Optimize MySQL indexing

---

# SEO Standards

- Semantic HTML
- Dynamic title/meta
- Sitemap.xml
- robots.txt
- OpenGraph support
